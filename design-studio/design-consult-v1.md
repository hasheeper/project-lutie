# Lutie 研究生活设施：空间设计工作台设计建议

## 0. 定位

这是一张**可以旋转的施工草图**，用来讨论空间，不是游戏界面。下面的建议都围绕三条原则展开：

1. **模型优先**：画布全屏铺满，面板浮在画布上方，可以折叠。
2. **信息分级**：每个数字都标明来源，"既有设定"和"暂定设计"一眼能分开。
3. **约束可校验**：改动标高后，楼梯、净空、视线、水深自动重算并给出提示。讨论的重点是空间关系，而不是数字本身。

## 1. 坐标与几何约定（建议先统一）

| 轴 | 方向 | 范围 |
|---|---|---|
| x | 西 → 东 | 0 → 12.5 |
| y | 向上，0 = 生活层地坪 | -2.2 → 约 +3.0 |
| z | 北 → 南 | 0 → 8.0 |

**分区边界：**
- Lutie 池区：x 0–5.2，z 0–4.8
- 观察室：x 5.2–8.325，z 0–4.8（玻璃在 x = 5.2 的西墙）
- 维生与培育区：x 8.325–12.5，z 0–4.8
- 人类生活区：x 0–12.5，z 4.8–8.0

> "池区前缘"我暂按**南缘**理解，即靠近生活区一侧，湿平台从 z = 4.8 向北伸入池内。如果你指的是靠观察窗的东缘，只需改一个参数。建议把它做成 `wetDeckEdge: 'south' | 'east'` 可切换。

**关键推导值**（工作台应自动计算并显示，不需要手填）：
- 水深 = -0.15 − (-2.2) = **2.05 m**
- 观察位眼点绝对标高 = -1.8 + 1.15 = **-0.65 m**，即**在水面下 0.50 m**。这是观察室最核心的体验：坐着时水面线在眼睛上方，看到的是水下景象。
- 观察室到生活层高差 **1.8 m**。按 11 级计算，踏步高约 0.164 m，踏面宽 0.28 m，水平长度约 2.8 m（2R+T ≈ 0.61，舒适）。
- Lutie 站在池底时头顶约在 -1.0 m，略低于眼点 -0.65 m，坐着的人看它是平视略偏俯视。站在浅台上时则随浅台标高变化，适合用它来调参。

## 3. 视觉语言：建筑图纸感，而非游戏感

**底色**：浅暖灰纸面（约 `#ECEBE6`），比深色背景更适合截图贴进讨论文档，标注也更清晰。可以提供一个深色切换，但不作为默认。

**模型渲染：轻材质 + 强轮廓。**
- 实体用 `MeshStandardMaterial`，低饱和、粗糙度高，不做反射。
- 每个构件叠加 `EdgesGeometry` 线框（深灰，1px）。轮廓是建筑图可读性的关键。
- 分区用极淡的底色区分，饱和度控制在 15–25%：
  - 池区：灰青
  - 观察室：中性灰
  - 维生与培育：灰绿
  - 生活区：暖米色

**水体**：
- 水面是 y = -0.15 处的半透明平面，透明度约 0.35，边缘画一圈青色实线作为"水线"。
- 水体是一个极淡的体积盒，透明度约 0.08，主要在剖切时显出水的范围。
- 剖切视图中，切面上的水体用横向细线填充（建筑图的水符号），而不是一块蓝色。

**玻璃**：不要用 `transmission`。它费性能，而且在图纸风格下反而看不清。用透明度约 0.15 的淡青色面，配一圈加粗的框线，玻璃的位置和尺寸就一目了然。

**暂定构件的视觉区分**（重要）：
- 既有设定的构件：实线轮廓。
- 暂定设计的构件（湿平台、浅台、坡、楼梯、家具、培育柱布置等）：**虚线轮廓**（`LineDashedMaterial`，记得调用 `computeLineDistances()`），面材质略偏暖。
- 提供"仅显示既有设定"开关，一键看出哪些东西还没定。

**尺度人**：
- Lutie 1.2 m：简化的胶囊体或剪影立牌，带头顶标高标签。默认放在池底，可以拖到浅台或湿平台上。
- 人 1.7 m（站姿）和坐姿人（眼高 1.15 m）：灰色剪影。
- 尺度人只用纯色剪影，不做细节，避免抢了建筑的戏。

## 4. 四个视图

| 视图 | 相机 | 用途 | 特殊表现 |
|---|---|---|---|
| **总览** | 透视，FOV 35°，东南上方 45° 俯视 | 整体关系 | OrbitControls 自由旋转，限制仰角不钻到地下太深 |
| **顶视** | 正交，正上方 | 平面布局、尺寸 | 显示 0.5 m 网格、总尺寸与分区尺寸标注；屋顶和上层构件自动隐藏 |
| **剖切** | 正交或低 FOV 透视，侧向 | 标高关系，核心视图 | 剪切平面 + 切面填充 + 标高符号 + 视线 |
| **观察位** | 透视，FOV 60°，眼点 (≈6.1, -0.65, 2.4)，朝西 | 体验验证 | 只允许原地转头（限制 yaw ±70°、pitch ±35°），不能移动 |

**视图切换**：相机位置和目标点做约 600 ms 的缓动插值。透视与正交之间不必硬插值，可以在动画中途淡入淡出切换。开启 `prefers-reduced-motion` 时直接跳转。

### 剖切视图（最值得投入的部分）

- 提供两条预设剖线：
  - **A-A**：东西向，z 约 2.4，穿过池、玻璃、观察室、培育区。这是看"眼点 / 水面 / 池底 / Lutie"关系的最佳剖面。
  - **B-B**：南北向，x 约 2.6 穿过池与湿平台，或 x 约 6.7 穿过观察室楼梯。
- 用滑杆连续移动剖切位置。顶视图里同步显示一条剖切线和投射方向箭头。
- 实现上用 `renderer.localClippingEnabled = true` 加材质级 `clippingPlanes`。
- **切面填充**是剖面能不能读懂的关键，被切到的墙和板要有深色实心截面。简单做法有两种：
  - 用 stencil 方法生成截面盖；
  - 对规则的盒状构件直接按剖线计算截面矩形，单独绘制。本项目几何以方盒为主，后者更省事也更稳。
- 剖面上叠加以下注记（用 CSS2DRenderer 或线几何绘制）：
  - 标高符号 ▽，标在 ±0.00 / -0.15 水面 / -1.80 / -2.20 / 浅台 / 湿平台；
  - **视线扇形**：从眼点 -0.65 发出，穿过玻璃，显示能看到池内哪些范围；
  - 水面线延伸穿过玻璃，标注"眼点在水面下 0.50 m"。

## 5. 图层开关

按"讨论时会想单独看的东西"分组，而不是按技术对象分组：

```
结构      ☑ 墙体  ☑ 楼板  ☐ 屋顶/顶板
水        ☑ 水面  ☑ 水体  ☐ 水下照明示意
池内      ☑ 池底  ☑ 水下浅台  ☑ 坡  ☑ 湿平台
界面      ☑ 观察玻璃  ☑ 门（含开启扇弧线）
垂直交通  ☑ 楼梯  ☐ 楼梯净空包络
设施      ☑ 家具  ☑ 培育柱  ☐ 维生设备
尺度      ☑ Lutie 1.2m  ☑ 人 1.7m  ☑ 坐姿观察者
注记      ☑ 尺寸  ☑ 标高  ☐ 视线  ☐ 分区名
```

- 每行前面放一个对应分区色或构件色的小色块。
- 图层组可以整组开关。按住 `Alt` 点击某个图层可以单独显示它（solo）。
- "楼梯净空包络"建议默认可见于剖切视图：在楼梯上方画一个 2.0 m 的半透明体积。如果它和 0 m 层楼板相撞，就标红。观察室地坪 -1.8 m，假如上方是 0 m 楼板，净高只剩约 1.5 m。所以观察室**很可能需要通高或局部挑空**，这正是工作台应该主动暴露的问题。

## 6. 参数面板（少量，带来源）

只放真正需要讨论的参数，每项都要带来源标签：

| 参数 | 默认 | 范围 | 来源 |
|---|---|---|---|
| 池底标高 | -2.20 | -3.0 ~ -1.5 | 暂定（概念假设） |
| 水面标高 | -0.15 | -0.4 ~ 0 | 暂定（概念假设） |
| 观察室地坪 | -1.80 | -2.2 ~ -1.2 | 暂定（概念假设） |
| 坐姿眼高 | 1.15 | 1.05 ~ 1.25 | 人体常规值 |
| 湿平台进深 | 1.2 | 0.6 ~ 2.4 | 暂定 |
| 浅台顶标高 | -0.9 | -1.6 ~ -0.3 | 暂定 |
| 浅台进深 | 1.0 | 0.5 ~ 2.0 | 暂定 |
| 剖切位置 | 2.4 | 随剖线 | 视图参数，非设计参数 |

总平面 12.5 × 8、分区宽度和进深、Lutie 1.2 m 只读显示，带锁形图标。

> 来源归类请你确认：我暂把**平面尺寸、分区划分、Lutie 身高**归为"既有设定"，把**所有标高**归为"暂定"，因为你说过标高属于概念假设。如果游戏设定中已有某些标高，改一下数据表即可。

**交互细节：**
- 滑杆和数字输入框并排，拖动时模型实时更新。
- 参数改过之后，值旁出现一个"已修改"圆点，并提供"恢复默认"。
- 支持方案快照：保存成 JSON，或编码进 URL hash，方便把链接直接发给别人讨论。

## 7. 读数与校验面板

### 三级来源标记（贯穿整个页面）

| 类型 | 标记 | 含义 |
|---|---|---|
| **既有设定** | 实心深色标签「设定」 | 不在本工作台讨论范围内 |
| **暂定设计** | 虚线框标签「暂定」 | 可调，模型中也是虚线 |
| **推导值** | 斜体 + 「=」前缀 | 由其他值计算得出，不可直接改 |

### 读数分组示例

```
分区面积
  池区          24.96 ㎡   设定
  观察室        15.00 ㎡   设定
  维生与培育    20.04 ㎡   设定
  生活区        40.00 ㎡   设定
  合计         100.00 ㎡   = 推导

垂直关系
  水深            2.05 m   = 推导
  眼点标高       -0.65 m   = 推导
  眼点低于水面    0.50 m   = 推导
  Lutie 头顶     -1.00 m   = 推导（站池底）

楼梯（观察室 → 生活层）
  高差 1.80 · 11 级 · 踏高 0.164 · 踏宽 0.28   = 推导
  水平长度 2.80 m              = 推导
  净空                       ⚠ 1.48 m < 2.0
```

### 校验项

每项显示 ✓ / ⚠ / ✕。点击某项时，相机飞到相关部位并高亮对应构件。

- 楼梯踏高在 0.15–0.18 之间，2R+T 在 0.60–0.64 之间
- 楼梯净空 ≥ 2.0 m
- 楼梯水平长度加底部平台能放进观察室进深 4.8 m，并给剩余观察区留出深度
- 湿平台与生活层的高差（如果湿平台高于水面）
- 坡度：从池底到浅台的坡比，以百分比和角度显示
- 观察玻璃覆盖范围：上沿要高于水面，下沿要低于眼点视线下限
- 浅台标高与 Lutie 身高的关系（站在浅台上时的露出水面高度）

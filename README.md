# 光与水的孩子 · Lutie

一款以露缇（Lutie）为中心的「近未来深海／以太科研箱庭养成与跨物种观察」游戏企划。玩家作为研究员，在温暖、幽静的半水下生态观察舱中照料她，通过日常互动逐渐理解一种与人类感知方式不同的生命。

当前重点是**生态观察舱主界面的概念设计与素材准备**。本目录汇集角色与世界设定、HUD 设计说明及主要美术素材，供 Koma 辅助理解、讨论和推进创作。

## 玩家在这里做什么

- **照料生态**：调整水温、湿度与以太光照，投喂软食，维持适合露缇生活的环境。
- **观察与互动**：点按观察窗、改变光源、隔着玻璃交流，观察她的反应与模仿学习。
- **切换感官**：在人类科研视角与露缇的非人感官视角之间切换，体验光斑、声波、情绪色彩和以太流动。
- **记录成长**：记录约八年生命周期中的成长片段，以及记忆晶核的变化。

体验的核心是安静的陪伴、好奇与逐步建立理解。界面中的仪表、按钮和反馈应服务于这些具体互动。

## 怎样理解露缇

露缇是幽影水凝体（Umbragel）的特殊智慧个体，具有水母与凝胶生命的特征：大型伞帽、凝胶长发、蓝绿色柔光，以及能够流动、拟态的身体。

她缺少人类常识，通过整体光场、振动、化学信号与以太变化感知世界；细节识别、复杂语言与步骤理解都有自己的局限。她的可爱来自好奇、模仿与跨物种认知差异。离水过久会脱水退化，强烈刺激可能造成感官过载，因此环境照料也应成为互动的一部分。

完整性格、物种机制与生命周期见[角色档案](characters/lutie/profile.md)。

## 画面应传达什么

观察舱是一个温柔、通透、可以长时间停留的空间。参考《深海迷航》的水下基地与沉浸式观察感，同时保留露缇带来的治愈、安静与生命温度。

- **角色与空间**：中央保留充足的水光空间，让露缇成为视觉焦点；HUD 沿观察窗边缘自然分布。
- **材质**：流体玻璃、凝胶膜、水滴与悬浮光环，结合轻微折射、水波焦散和细腻光丝。
- **色彩**：环境以深海青蓝为底，露缇以薄荷青荧光呼应，少量琥珀与暖白点出温度和以太能量。
- **信息密度**：围绕照料、互动、感官切换与成长记录保留必要反馈，避免厚重面板和密集数据遮挡观察。

当前设计对象是游戏内的空间化 HUD。完整功能意象与视觉要求统一维护在 [HUD 设计资料](lore/game-hud.md)。

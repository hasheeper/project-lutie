# Lutie：深海／以太生态观察游戏 HUD 设计资料

整理日期：2026-11-16。来源：用户提供的项目核心设定。

供 Koma ASK 在指导本企划的概念主界面、美术生成与 HUD 迭代时参考。本文描述游戏内 HUD，不是 Koma 应用自身的界面改造要求。

## 项目核心

这是一款“近未来深海／以太科研箱庭养成与跨物种观察”游戏的概念主界面（Game HUD，非网页 UI）。

玩家扮演研究员，透过一座温暖而幽静的半水下生态观察舱，照料并观察“水母凝胶少女”Lutie——一种没有人类常识、靠光线与化学信号感知世界、离开水太久会脱水退化的特殊生物。

## 核心玩法意象

以下玩法决定界面功能。

1. **生态微调与维生照料**：维持水体温度、空气湿度、以太光照强度，防止她脱水或感官过载；投喂果冻等软食。
2. **第一人称交互观察**：通过点按观察窗、调整光源、隔着玻璃互动，观察她天然呆的反应与模仿学习。
3. **双重视角／感官切换**：可在人类科研视角与 Lutie 的非人感官视角之间切换；后者表现为模糊光斑、心跳声波纹、情绪色彩与以太流向。
4. **生命周期记录**：记录她 8 年轮回的成长片段与“记忆晶核”状态。

## 视觉基调与 UI 设计语言

### 核心参考感

参考《深海迷航（Subnautica）》的沉浸式游戏 HUD 与海底基地观察窗氛围，但整体更温柔、治愈、通透。

### 材质与质感

- **流体玻璃与凝胶（Liquid Glass & Bio-Gel）**：拒绝直角矩形和死板的网页卡片边框。界面控件呈现水滴边缘、半透明折射玻璃、柔韧凝胶膜或悬浮光环的形态，带有轻微的水波焦散光影。
- **光源驱动**：UI 本身像是由微弱的生物荧光、水面折射光和细腻的全息光丝构成，没有厚重不透明的遮挡物，保持画面的呼吸感与水下空间感。

### 防止网页化

采用空间化／沉浸式 HUD（Diegetic UI）：用轻微的曲面弧度、观察窗玻璃接缝或细微的扫描光栅暗示“隔着玻璃观察”，控件顺着屏幕边缘或空间透视自然分布，中心留出大片干净的水光空间给角色。

### 色彩语言

- 深邃宁静的海底青蓝：环境底色。
- 角色本身的薄荷青荧光：主光源。
- 微弱琥珀／暖白光点：象征生命温暖与以太能量。

## 画面结构建议

保持灵活，供自由发挥。

### 画面中心

角色置于充满水下光影与浮游微粒的生态水舱中，或站在水陆交界浅水平台前，成为绝对的视觉焦点和核心光源。

### 边缘 HUD

精简、克制的游离式仪表与交互组件，例如：

- 仅以水滴充能条／光环弧线暗示水分与情绪状态。
- 角落一个简洁的“感官视角切换”晶体按钮。
- 极简的观察日志／互动光点提示。

不要堆砌过多文字和密密麻麻的数据表格。
